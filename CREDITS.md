# Night Patrol — Credits

Made by Clarence Kennedy (Grandpa) for the family.

## Code
- Game code: original, written for this project.
- Engine: [Phaser 3.80.1](https://phaser.io) — MIT License, (c) Richard Davey / Phaser Studio. Vendored at `vendor/phaser.min.js`.

## Art
- All graphics (heroes, monsters, city, sky, icons) are generated procedurally in code at runtime (`src/art.js`) or by a small script (icons). No third-party image assets. Released as CC0 with this project.

## Sound
- All sound effects and ambience are synthesized live with the Web Audio API (`src/audio.js`). No recorded audio files. CC0.

## Characters
- WEAVER, BLASTER, SHADE and the Hollow King are original characters. WEAVER is a web-slinging hero *inspired by* classic comic web-swingers but uses no Marvel names, logos, costumes or likenesses.

## Privacy
- No ads, no chat, no accounts, no analytics, no network calls besides loading the game itself. Settings and progress are saved only on the device (localStorage).
